Totufoto 0.1.7 fixes an empty People tab and photos that stayed after removing their folder.

## Downloads

- **Windows 10/11**: `Totufoto-0.1.7-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Linux (x86-64)**: `Totufoto-0.1.7-linux-x86_64.AppImage`. Run `chmod +x Totufoto-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

## Fixes

- **People tab**: opened while the library had nobody yet (a new library still being indexed, for example), it showed grey placeholder cards that never went away, even once people were found. It now says so and fills in as soon as there are people.
- **Removing a folder**: the photos and the Optimization report behind Settings now update at once, and a message says how many photos were removed. A folder now leaves the list only after its photos are gone, so a failure can't leave photos that no folder includes. If photos of a folder removed with an earlier version still show, add that folder again and remove it.
