Imadive 0.1.12 is quicker to move around in, works fully from the keyboard, and the desktop app now keeps a log you can attach when something goes wrong.

## Downloads

- **Windows 10/11**: `Imadive-0.1.12-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Linux (x86-64)**: `Imadive-0.1.12-linux-x86_64.AppImage`. Run `chmod +x Imadive-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

New: each download can be checked. `SHA256SUMS` lists the files' checksums, and every file carries a signed record of the GitHub build it came from (`gh attestation verify <file> --repo JaviEspinar/totufoto`).

## What's new

- **A log for the desktop app**: it writes one to its data folder, keeping the previous run's too. *Settings → About → Open log folder* shows it, ready to attach to a problem report.
- **Instant arrows in the viewer**: the details of the photos you have seen are kept, and the next photo's are fetched ahead.
- **The keyboard reaches everything**: month and place cards, people's faces and names, and the people to pick in *Same as…* can be opened with Enter or Space. The viewer keeps the focus inside while it is open and gives it back to the photo when it closes.
- **About** in Settings: the version, the license and links to the project.
- **"Can't reach Imadive"**: if the program stops or the network drops, the page says so instead of silently standing still, and says so again when it's back.
- **Try again**: a tab that couldn't load offers to try again.
- Screen readers get labels for the buttons and checkboxes, and *Reduce motion* in your system settings now turns off the gallery's animations.

## Fixes

- **Disk space**: the desktop app deleted nothing it unpacked for older versions, about 100 MB per update. It now removes those copies on start, and checks the files it unpacks byte for byte, so a damaged one is written again.
- **Large duplicate searches**: while a search runs, Optimization no longer downloads the whole report every second, which was slow with tens of thousands of copies.
- **Dark mode**: red buttons and error messages are easier to read.
- Several failures that went unnoticed now show a message: a photo whose details couldn't load, a duplicate search that failed, a link that couldn't open.
