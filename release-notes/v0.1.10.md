Totufoto 0.1.10 keeps your photos safer: photos on an unplugged drive stay in the gallery, edited photos keep their place, and other websites can no longer use the gallery through your browser. It is also the first version with a license.

## Downloads

- **Windows 10/11**: `Totufoto-0.1.10-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Linux (x86-64)**: `Totufoto-0.1.10-linux-x86_64.AppImage`. Run `chmod +x Totufoto-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

## Fixes

- **Photos on an unplugged drive**: on Linux, a drive that isn't mounted leaves an empty folder behind, and the gallery took all its photos for deleted, with their faces. A photo folder that is missing or completely empty now counts as unavailable: its photos stay, and Settings shows it as *not available*.
- **Edited photos keep their place**: a photo whose file changed (edited in another app, say) used to come back as a new photo. It now keeps its place, and its faces are found again.
- **Removing a folder** that contains a folder given on the command line no longer removes that folder's photos too (a problem since 0.1.8).
- **Never stuck as busy**: a file that crashes while being read no longer stops the scan (it is listed as a file that couldn't be read), and a scan or a duplicate deletion that fails no longer stays "running" until the app is restarted.
- A deleted photo's file now answers "not found" instead of an error, and error messages read as sentences everywhere.

## Security

- Other websites can no longer use the gallery through your browser, also when it is shared with your network: requests for a name that isn't an IP address, `localhost` or the computer's own name are refused (this blocks DNS rebinding), and requests that change something are refused when they come from another site.
- **If you open the gallery through a name** (for example one set on your router, like `photos.home`), start the command-line app with `--allow-host photos.home`. IP addresses, `localhost` and the computer's own name work as before.
- The README and the new SECURITY.md say plainly what anyone on your network can do with a shared gallery, since it has no login.

## For people building it

- Rust 1.93 or newer is needed (1.88 was listed, but a dependency already needed 1.93).
- The face model and ONNX Runtime downloads are checked against SHA-256 checksums. ONNX Runtime no longer publishes a build for Intel Macs; there the gallery runs without face recognition.
- Automated checks on every change (formatting, lints, and 48 tests on Linux, macOS and Windows).
