Totufoto is now **Imadive**. Same app, new name; your library comes with you.

## Downloads

- **Windows 10/11**: `Imadive-0.1.11-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Linux (x86-64)**: `Imadive-0.1.11-linux-x86_64.AppImage`. Run `chmod +x Imadive-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.

## Moving from Totufoto

- **Desktop app**: close Totufoto and start Imadive. On its first start it moves Totufoto's library (names, people, folders and the index) to its own data folder, so nothing is indexed again. You can delete the old Totufoto file afterwards. If the old app was still running, Imadive uses the old folder that time and moves it on the next start.
- **Command-line app**: the program is now called `imadive`. After `git pull` and `cargo build --release`, point your start command or service at `target/release/imadive`; the old `target/release/totufoto` file stays there and would keep running the old version. Without `--data`, Imadive uses `./imadive-data`, or your existing `./totufoto-data` if only that one exists.
- Preferences saved in the browser (people layout and sizes, collapsed panels) carry over too.

Nothing else changes in this version; see [0.1.10](https://github.com/JaviEspinar/totufoto/releases/tag/v0.1.10) for the latest fixes.
