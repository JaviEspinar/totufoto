Imadive 0.3.2 reads the date and place of more videos.

## Downloads

- **Windows 10/11**: `Imadive-0.3.2-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Debian, Ubuntu and Linux Mint** (Debian 12 or Ubuntu 22.04 and newer): `Imadive-0.3.2-linux-amd64.deb`. Install it with `sudo apt install ./Imadive-0.3.2-linux-amd64.deb`, then start Imadive from the applications menu.
- **Other Linux distributions (x86-64)**: `Imadive-0.3.2-linux-x86_64.AppImage`. Run `chmod +x Imadive-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

Each download can be checked: `SHA256SUMS` lists the files' checksums, and every file carries a signed record of the GitHub build it came from (`gh attestation verify <file> --repo JaviEspinar/totufoto`).

## Fixes

- **Videos edited or converted with FFmpeg-based tools** (and the apps built on them) now show the date and place they were recorded, instead of the file's date and no place. Those tools keep the recording's date and place in a different part of the file than phones do; the gallery now reads both. Videos already in the gallery are read again when their file changes; to update them now, remove their folder in Settings and add it again.
