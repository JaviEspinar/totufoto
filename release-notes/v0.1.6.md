Totufoto 0.1.6 shows the indexing progress where you can see it, without opening Settings.

## Downloads

- **Windows 10/11**: `Totufoto-0.1.6-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Linux (x86-64)**: `Totufoto-0.1.6-linux-x86_64.AppImage`. Run `chmod +x Totufoto-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

## What's new

- **First start**: while the library is still empty, the Photos tab shows the indexing progress (photos done, faces found) until the first photos are in.
- **Progress card**: after that, a small card at the bottom right shows indexing and face grouping on every tab. **Show N new** brings in the photos indexed since, **Details** opens Settings, and **Hide** hides it until the next scan. It says when the library is up to date, then goes away.
- Quick checks for changes that find nothing new don't show the card.

See [0.1.5](https://github.com/JaviEspinar/totufoto/releases/tag/v0.1.5) for deleting photos, duplicate files, rotating, card photos and managing several folders.
