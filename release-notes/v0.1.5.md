Totufoto 0.1.5 can now change your library: delete photos, free space taken by duplicate files, and rotate photos. It also lets you manage several photo folders from Settings, even when the app is started with a folder.

## Downloads

- **Windows 10/11**: `Totufoto-0.1.5-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Linux (x86-64)**: `Totufoto-0.1.5-linux-x86_64.AppImage`. Run `chmod +x Totufoto-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

## What's new

### Deleting photos
- A bin button in the photo viewer (or the `Delete` key) asks how: **Remove from gallery** keeps the file and leaves it out of later scans (Settings can bring such photos back); **Remove from disk** moves the file to the bin. If its drive has no bin, it asks before deleting it for good.
- Only files inside your photo folders can be deleted.

### Optimization: duplicate photos
- A new **Optimization** tab finds identical files (the very same bytes) and shows how much space they take.
- Of each set, the copy with the oldest file date is kept (**Keep**); the others are marked **To delete**. Nothing is deleted until you click **Delete duplicates** and confirm.
- Deleting shows a progress bar with the files done and the space freed, also if you leave the tab and come back.
- Duplicates are moved to the bin; empty it to get the space back.

### Rotating photos
- Two rotate buttons under the photo's date (or `R` and `Shift+R`) turn the photo, and the file is saved turned.
- JPEG photos are turned through their EXIF orientation, so the picture is not compressed again and loses no quality; PNG is rewritten turned. Other formats (HEIC, WebP, GIF, TIFF) can't be rotated.
- The photo turns on screen at once; several quick turns are saved once. Faces and people stay as they are, and the photo is not indexed again.

### Photo viewer
- **Download** saves the original file with its own name (HEIC and TIFF as JPEG).
- In the desktop app, **Share** opens the system share sheet with the photo where the system offers one, and **Open in folder** shows the file in Finder, Explorer or the Linux file manager.
- **Card photo** next to each face makes it the face shown on that person's card in People.

### Photo folders
- Settings can add and remove photo folders also when the app is started with folders on the command line; those are always included and marked **command line**.
- In the browser, **Add folder…** lets you browse the folders of the computer running Totufoto (or type a path) instead of typing the whole path.
- A folder already inside another one is refused, and removing a folder keeps the photos another folder still includes.
- Removing a folder asks with the app's own dialog.
