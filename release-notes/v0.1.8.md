Totufoto 0.1.8 makes removing a photo folder clear and reliable.

## Downloads

- **Windows 10/11**: `Totufoto-0.1.8-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Linux (x86-64)**: `Totufoto-0.1.8-linux-x86_64.AppImage`. Run `chmod +x Totufoto-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.

Your folders, people names and index carry over from earlier versions; nothing is indexed again.

## Removing a folder

- **Progress**: the folder's row in Settings shows "Removing 1,200 of 40,000 photos" with a bar, and the progress card at the bottom right shows it on every tab. A message says how many photos were removed when it's done.
- **One at a time**: while a folder is being removed, Remove and Add folder are disabled, so clicking again does nothing.
- **No photos coming back**: a scan still running (for example of the folder you just added) stops first, so it can't put the photos back; the other folders are scanned again afterwards.
- It finishes even if you close the window or reload the page meanwhile.
