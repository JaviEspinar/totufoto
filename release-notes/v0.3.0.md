Imadive 0.3.0 brings videos into the gallery, the app in Spanish, a light or dark theme of your choice, a new look, and a package for Debian and Ubuntu.

## Downloads

- **Windows 10/11**: `Imadive-0.3.0-windows-x64.exe`. Double-click it. It is not signed, so the first time Windows may show "Windows protected your PC": click **More info**, then **Run anyway**.
- **Debian, Ubuntu and Linux Mint** (Debian 12 or Ubuntu 22.04 and newer): `Imadive-0.3.0-linux-amd64.deb`. Install it with `sudo apt install ./Imadive-0.3.0-linux-amd64.deb`, then start Imadive from the applications menu.
- **Other Linux distributions (x86-64)**: `Imadive-0.3.0-linux-x86_64.AppImage`. Run `chmod +x Imadive-*.AppImage`, then start it. If it says FUSE is missing, install `libfuse2` or run it with `--appimage-extract-and-run`.

Your folders, people names and index carry over from earlier versions; nothing is indexed again. The next scan adds the videos in your folders.

Each download can be checked: `SHA256SUMS` lists the files' checksums, and every file carries a signed record of the GitHub build it came from (`gh attestation verify <file> --repo JaviEspinar/totufoto`).

## What's new

- **Videos** (MP4, MOV, M4V, 3GP, WebM, MKV, AVI, WMV, MPEG and MTS) join the timeline, places and Upcoming, with their length in a corner. Their date and place come from the file, as phones and most cameras record them.
  - They play in the viewer as soon as you open them.
  - Their thumbnail is a frame from about a second in, made by your browser the first time it shows them and kept for everyone, or the picture a camera saved beside them (`.THM`).
  - Videos whose sound your browser can't play (many sent with WhatsApp) play without sound, with a note saying so.
  - Formats your browser can't play offer the file to download instead.
- **Spanish**: choose English or Español in Settings. Without a choice, the gallery uses your browser's language when it has it, and English otherwise.
- **Light or dark**: Settings lets you pick the theme, or follow the system as before.
- **A new look**: the ImaDive name and icon in the top bar (the icon alone on phones), and in the browser tab. Click it for the version, and a link to support the project on Ko-fi if you like it.
- **Tabs** in the order Photos, People, Upcoming, Optimization.
- **A .deb package** for Debian, Ubuntu and Linux Mint, next to the AppImage.

## Known issues

- Videos have no people: faces are only looked for in photos.
- A video's thumbnail is made by the first browser that can play it. Until then, and for formats no browser plays, it shows a generic picture with a play sign. iPhone videos (HEVC) only play in some browsers.

## For scripts using the API

If you only use the gallery in a browser or the desktop app, you can skip this. With videos in the gallery, what the API called a photo is now an item (details in [docs/api.md](https://github.com/JaviEspinar/totufoto/blob/main/docs/api.md#changes-in-03)):

- `/api/photos` is now `/api/items`, with `/api/items/{id}` and its `/check`, `/reveal` and `/rotate`. The list answers `{"items": [...]}`.
- Each row has a seventh value, `duration`: null for photos, a video's length in seconds otherwise. `/api/groups` counts `videos`, and `/api/items/{id}` gives `duration`.
- Each folder of `GET /api/folders` counts its `items`, instead of `photos`.
- The scan phase `indexing photos` is now `indexing files`.
- New: `PUT /api/items/{id}/thumb` stores a video's thumbnail made by the page, `/thumb` answers `204` for a video without one, and `?silent=1` on `/original/{id}` serves a video without its sound.
